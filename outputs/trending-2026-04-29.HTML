Editor's Take

The AI-agent ecosystem is splitting into two clear layers: platforms and plumbing. This week's breakout, open-design, proves that Claude Code's skill architecture is now a de facto standard — projects ship as skills first, standalone tools second. Meanwhile the 30-day window tells a starker story: four of the top five repos are either memory systems or token-economy hacks, which means the community has moved past "can I build an agent?" to "can I afford to run one?" The most underrated signal is future-agi and codeburn converging on the same problem from opposite ends — eval and cost observability are becoming table stakes, not afterthoughts. If you are building agent infrastructure without a metering story, you are already behind.
