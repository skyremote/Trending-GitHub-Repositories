# Trending AI Repos — 2026-05-18

## Editor's take

The agent ecosystem is quietly stratifying into three tiers: platforms that other agents run on, skills that plug into those platforms, and educational material that teaches people to build both. This week, `html-anything` crossed 2,800 stars by treating the browser as a universal canvas agents can paint on, while `guizang-ppt-skill` dominated the month by doing the same for slide decks — both betting that agents should produce finished artifacts, not intermediate text. Meanwhile, infrastructure plays like `pgGraph` (graph queries on existing Postgres) and `orthrus` (faster LLM decoding via diffusion) are solving the plumbing problems that emerge once agents actually ship to production. The signal: if your repo helps an agent *do* something concrete — generate a CAD file, file a legal brief, search code semantically — it gets stars. Wrappers and prompt libraries are stalling.
