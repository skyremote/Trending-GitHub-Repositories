# Trending AI Repositories — 2026-05-20

## Editor's Take

The AI open-source scene this week is defined by two forces: **agent infrastructure** and **local inference**. Vercel's `zerolang` introduced a purpose-built programming language for agents, drawing 3,300+ stars in five days — a signal that the industry is moving past "wrap an LLM in a loop" toward first-class agent primitives. Meanwhile, antirez's `ds4` (10,800+ stars) proved that a single developer can ship a serious DeepSeek inference engine for consumer hardware, and `lightseekorg/tokenspeed` is pushing speed-of-light serving claims. The "skills" ecosystem around Claude Code and Codex continues to explode: `guizang-ppt-skill` (10,400+ stars) and `html-anything` (4,000+) show that reusable agent skills are becoming the new npm packages. The most useful new repo this week may be `smallcode` — a coding agent that hits 87% benchmarks with only a 4B-parameter model, challenging the assumption that capable agents need frontier-scale LLMs. Infrastructure picks like `mirage` (unified virtual filesystem for agents) and `deepsec` (security harness) suggest the ecosystem is maturing past demos into production tooling.
