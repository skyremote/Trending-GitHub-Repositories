Editor's Take

The coding-agent arms race has entered its observability phase. The week's top new repo is Moonshot's kimi-code, a full coding agent from a Chinese lab — but the signal is in the second tier: ccglass (proxy dashboard to see what your agent actually sends), ai-memory (cross-vendor long-term memory in Rust), and codeindex (blast-radius scoring before an agent touches your code). Builders have stopped asking "which agent?" and started asking "what is my agent doing, and how do I keep it honest?" Meanwhile, the 30-day chart shows html-anything pulling nearly 5k stars for an agentic HTML editor — evidence that skill-based agent UX is the wedge into non-developer audiences. If you ship an agent today without an observability story, you are already behind.
