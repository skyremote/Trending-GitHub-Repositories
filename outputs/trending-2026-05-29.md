# Trending AI Repos — 2026-05-29

## Editor's Take

The agent-infrastructure stack is crystallizing into distinct layers this week. At the bottom, new runtimes and filesystems ([zerolang](https://github.com/vercel-labs/zerolang), [mirage](https://github.com/strukto-ai/mirage)) define how agents interact with code and files. In the middle, skill optimizers and memory-native runtimes ([SkillOpt](https://github.com/microsoft/SkillOpt), [opensquilla](https://github.com/opensquilla/opensquilla)) compete on token efficiency. At the top, a wave of "how it works" repos and structured courses signal that practitioners have moved past "use an agent" to "understand and customize the agent loop." The 7-day window is dominated by Claude Code ecosystem projects — skills, harnesses, and architecture teardowns — suggesting the skill-as-distribution-unit pattern is gaining real traction. Meanwhile, Vercel shipped both a language and a security scanner for agents in the same month, a bet that agents need purpose-built tooling, not bolted-on linters.
