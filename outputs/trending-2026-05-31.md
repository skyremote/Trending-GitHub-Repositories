## Editor's Take

The AI open-source scene this week is dominated by two forces: **agent infrastructure** and **developer tooling for vibe-coding**. The standout launch is `html-anything` (5.4k stars in under three weeks), which turns any LLM coding agent into a full HTML publishing pipeline — a sign that the "agent as creative tool" paradigm is maturing fast. Meanwhile, the educational side is thriving: `how-to-train-your-gpt` proves there is still massive appetite for from-scratch LLM tutorials, and `Agent_Memory_Techniques` fills a gap that everyone building agents has hit — how to give them memory that actually works. The agent-security angle is emerging too, with `AgentGuard` introducing access control for tool-using agents — a problem that will only get louder as autonomous agents ship in production. The broader 30-day view shows the ecosystem converging on a stack: MCP for tool integration, skills for extension, and persistent memory for context. If you build AI tools, this is the infrastructure wave to watch.
