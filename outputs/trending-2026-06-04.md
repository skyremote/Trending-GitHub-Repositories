## Editor's Take

The agent infrastructure layer is solidifying fast. This week's standout signal: developers are no longer just building *with* AI agents — they're building the operating systems, filesystems, and programming languages those agents need to function autonomously. Microsoft's SkillOpt treats natural-language instructions as optimizable artifacts, Vercel shipped a language where agents are first-class citizens, and strukto-ai built a virtual filesystem so agents can operate in sandboxed environments without tripping over real disk I/O.

Meanwhile, the 7-day window tells a complementary story. Memory, governance, and trust are emerging as the hard problems. ClaudioDrews/memory-os implements a 7-layer persistent memory stack — the kind of plumbing every long-running agent will eventually need. On the security side, both `vigils` (agent oversight) and `PentesterFlow/agent` (offensive security) reflect the industry waking up to the fact that agents with tool access require guardrails, not just prompts. NVIDIA's dvlt paper reminds us that multi-modal transformer research continues to advance quietly while the agent hype cycle plays out above it.

The bottom line: if May was about agent demos, June is about agent reliability.
