# Trending AI Repos — 2026-06-05

## Editor's take

The agent ecosystem has split into two clear layers this week: the agents themselves and the infrastructure that keeps them honest. Memory systems (memory-os, ai-memory), sandboxing (sandboxes, vigils), and rule-synchronization tools (ai-rules-sync, meta-llm-charter) are accumulating stars faster than new agent shells. That inversion matters. It means the community has moved past "can an LLM write code?" and is now debugging "how do we supervise and persist what the LLM knows?" Meanwhile, Rust keeps gaining ground as the language of choice for performance-sensitive agent internals — zerostack, vigils, and rmux all ship Rust cores. The week's quiet signal: small-model agents (smallcode hitting 87% on a 4B-active model) are pulling within striking distance of frontier-hosted agents on coding benchmarks, which will compress margins for API-only providers faster than most pricing models assume.
