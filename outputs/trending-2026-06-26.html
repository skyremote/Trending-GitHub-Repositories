Editor's Take

The agent infrastructure layer is consolidating fast. This week's standout pattern: the market has moved past "build an agent" and into "build the thing agents run inside." Sandboxing (tupper), orchestration (omnigent), and agent-native dev environments (peerd, Accordion) are all racing to become the default substrate. Meanwhile, Xiaomi's MiMo-Code signals that non-US big tech is shipping full coding-agent products, not just foundation models. The sleeper hit is PixelRAG — ditching text extraction entirely in favor of pixel-native search is an architectural bet that, if it scales, obsoletes an entire class of parsing tooling. If you're building agent infrastructure, the competitive window is narrowing. If you're building on top of agents, the tooling has never been better.
