# Trending AI Repositories on GitHub

**Date:** 2026-06-28 (UTC)

---

## Editor's Take

The AI open-source landscape this week is dominated by a clear thesis: agents need better infrastructure, not more wrappers. The standout 7-day entry, `theeleven`, shows autonomous AI agents breaking into real-money DeFi markets — a concrete use case while most agent projects are still demo-ware. Meanwhile, `Godcoder` suggests developers are tired of cloud-locked coding assistants and want local-first alternatives they actually control.

On the 30-day horizon, the sheer velocity of `odysseus` (78K+ stars) signals massive pent-up demand for self-hosted AI workspaces. The pattern is unmistakable: developers want to own their AI stack. `ponytail` took a different angle — not building new AI capabilities but constraining them, teaching agents to write less code rather than more. That it hit 60K+ stars says something about where the pain actually is.

The most technically interesting entry is Xiaomi's `MiMo-Code`, which treats model training and agent behavior as a co-evolution problem rather than separate concerns. If that approach proves out, the current split between "model people" and "agent people" may not last.

Three themes to watch: agent evaluation (`awesome-evals`), agent memory (`memory-os`), and the browser as an agent runtime (`peerd`).
