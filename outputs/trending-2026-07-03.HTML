Editor's Take

Agent skills are the new packages. This week's 7-day window is almost entirely composable agent capabilities — self-learning loops, video understanding, reverse-engineering flows — rather than standalone agents or models. The shift mirrors what happened to web development a decade ago: once the framework wars settled, the ecosystem moved to plugins. The 30-day view confirms the pattern at scale: ponytail (71k stars in three weeks) proves that a single well-scoped skill can outpace entire agent frameworks in adoption. Builders still launching new agent runtimes are arriving late; the leverage is now in what agents can do, not how they run.
