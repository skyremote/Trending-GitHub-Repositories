# Trending AI Repositories — 2026-07-19

## Editor's Take

The coding-agent ecosystem just got its biggest signal yet: xAI dropped `grok-build` and sucked up 19k stars in five days flat. That one repo now has more forks than most frameworks get in a year. But look past the headline number and you see the real story — the infrastructure layer around agents is filling in fast. Memory (deja-vu), auth (open-connector), security testing (T3MP3ST, LLMVault), and cross-agent harnesses (agentsmith) all shipped this month. The market is no longer asking "should we use AI agents?" but "how do we operate them safely at scale?" Meanwhile, steganography via LLMs is a reminder that every capability cut both ways.

### Highlights

**[xai-org/grok-build](https://github.com/xai-org/grok-build)** — SpaceXAI's coding agent harness and TUI. Fullscreen, mouse-interactive, extensible. Written in Rust. 19k stars in under a week makes this the fastest-growing AI dev tool of the month. The TUI-first approach signals that terminal-native developer experience is still winning mindshare over browser-based IDEs.

**[nethical6/conversation-steganography](https://github.com/nethical6/conversation-steganography)** — Uses LLMs to hide messages inside normal-looking conversations. A dual-use technique with obvious security implications. The Go implementation is clean and the concept is immediately practical for both privacy research and threat modeling.

**[Blueturboguy07/cue](https://github.com/Blueturboguy07/cue)** — Open-source macOS AI copilot that floats over your screen, sees and hears your meetings, and stays hidden. Ambient AI assistants are becoming the next battleground after chat and code completion.

**[PengZhang64/circuit-framework](https://github.com/PengZhang64/circuit-framework)** — Multi-agent LLM trading research system. Connects multiple specialized agents for quantitative trading workflows. Interesting as a vertical-specific agent orchestration pattern.

**[vshulcz/deja-vu](https://github.com/vshulcz/deja-vu)** — Memory layer for coding agents. Search, MCP recall, auto-context, secret redaction, stats. Works with Claude Code, Codex, opencode, Cursor, Gemini CLI, aider, and more. One zero-dep binary in Go. Solves the "agents forget everything between sessions" problem.

**[PromptPartner/agentsmith](https://github.com/PromptPartner/agentsmith)** — Universal, model-agnostic operating harness for AI agents. A lean core plus work-type profiles assembled by one setup script. Targets Claude, Codex, and Gemini with a single abstraction layer.

## Themes This Week

- **Agent infrastructure dominance**: 8 of 15 repos are tools for building, operating, or securing AI agents rather than end-user applications.
- **Security cuts both ways**: Steganography, red teaming, and vulnerability labs all trending simultaneously. The offense/defense arms race is accelerating.
- **Memory and auth**: The two biggest unsolved problems for deployed agents (persistent context and authenticated API access) both got serious open-source answers this month.
- **Terminal-first UX**: grok-build and deja-vu both bet on CLI/TUI over GUI. Developers building for developers still prefer the terminal.
