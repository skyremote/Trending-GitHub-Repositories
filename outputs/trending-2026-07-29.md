# Trending AI Repositories — 2026-07-29

## Editor's Take

The agent wars are fully underway. xAI shipped [Grok Build](https://github.com/xai-org/grok-build), a Rust-based coding agent TUI, two weeks ago and it already has 23k stars — a clear signal that developers want choice beyond Claude Code and Codex. Meanwhile, the infrastructure *around* agents is where the real action is: ECC (235k stars) optimizes how agent harnesses perform, Graphify (98k stars) turns codebases into queryable knowledge graphs, and Caveman (94k stars) proves you can save 65% of tokens by teaching your agent to talk like a caveman. The trend is clear: raw model capability matters less than the tooling layer that sits between you and the model. On the research side, Unicity's open Agent Operating System and Synthetic Sciences' OpenScience workbench suggest the next frontier is structured, reproducible agent orchestration rather than single-shot prompting. If you're building with AI agents today, the repos to watch aren't the models — they're the harnesses, skills, and memory systems that make models useful.
