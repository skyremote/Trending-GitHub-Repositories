Editor's Take

The month's clearest signal is that every computing surface is getting an agent harness. Phone, macOS desktop, iOS Simulator, x64dbg, the browser — each gained a dedicated bridge this cycle, all converging on the same pattern: thin shim, full tool access, model-agnostic. The harness wars have replaced the wrapper wars. Meanwhile, the most-starred AI repo of the past 30 days is a tool for stripping AI provenance marks from every common file format (17k stars in two weeks). Whether you read that as a privacy tool or an accountability problem depends on your position, but the demand curve is unambiguous. On the builder side, agent routing is growing up: Sprix's SELF/COLLABORATE/HANDOFF state machine for A2A networks is the first credible open-source answer to "which agent should handle this subtask," a question most frameworks still punt to the user.
