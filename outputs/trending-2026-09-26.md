# Trending AI Repositories — 2026-09-26

## Editor's Take

The Jev ecosystem dominated this week. TypeSafe AI's "System One" decision model — a classifier that returns typed probability distributions in a single forward pass, no output tokens generated — spawned at least six major repos in seven days. Chat assistants on Android, Windows, and macOS now use Jev to read conversations and suggest replies without hooking into apps. Nokia Research published AnyJev, showing any off-the-shelf LLM can replicate the pattern without fine-tuning. The velocity suggests Jev is filling a real gap: agents need fast, cheap binary decisions more often than they need long-form generation.

Meanwhile, Z.ai's ZCode landed as a direct competitor in the coding-agent space, pulling nearly 7k stars in under a week. Magpie quietly solved a practical headache — letting developers swap the backing model behind Claude Code, Codex, or Gemini CLI from a menu bar — and its 800 stars in three days signal how real that friction is.

On the 30-day radar, Reef (self-improving agent loops), BrowserKitten (select-on-page web agent), and Sepia (de-AI writing for 77+ agents) each crossed 2,800 stars. The thread connecting all three: agents are moving past "chat with an LLM" toward specialized infrastructure — memory, decision, perception, and style as separable modules.

## Top 10 — Last 7 Days

Repos created September 19–26, 2026, ranked by stars.

### 1. [zai-org/ZCode](https://github.com/zai-org/ZCode)

**6,782 stars** · TypeScript · Created Sept 20

Z.ai's coding agent harness. Positions itself as a powerful, extensible alternative in the agentic coding space. Gained 2,000+ forks in under a week, indicating strong community experimentation.

### 2. [jev-chat/jev-chat-jarvis](https://github.com/jev-chat/jev-chat-jarvis)

**6,530 stars** · Kotlin · Created Sept 21

On-phone conversation copilot for QQ, X, and Feishu. Uses Android accessibility services to read the screen, runs the Jev decision model to understand intent, and surfaces candidate replies users can inject with one tap. Read-only — no app hooking or packet modification.

### 3. [yetone/magpie](https://github.com/yetone/magpie)

**811 stars** · Go · Created Sept 23

Menu-bar model router for macOS. Lets you point any coding agent — Codex, Claude Code, Gemini CLI — at any model provider (DeepSeek, Kimi, etc.) without reconfiguring each tool. Solves the "every agent wants its own model config" problem in one place.

### 4. [freestylefly/WeChatBridge](https://github.com/freestylefly/WeChatBridge)

**737 stars** · Swift · Created Sept 21

Native macOS tool that forwards WeChat chat history to AI agents and Obsidian. Uses the system share extension — no WeChat API abuse. Targets users who want LLM-assisted review of their conversations alongside a personal knowledge base.

### 5. [nokia-applied-research/AnyJev](https://github.com/nokia-applied-research/AnyJev)

**724 stars** · Python · Created Sept 21

Nokia's research contribution to the Jev wave. Demonstrates how to extract Jev-style typed decisions and real probability distributions from any LLM — no training required. Supports vLLM and HuggingFace Transformers backends.

### 6. [yukitorido/short-video-generator-AI](https://github.com/yukitorido/short-video-generator-AI)

**673 stars** · Python · Created Sept 23

End-to-end pipeline for generating vertical short-form videos from long content. Chains LLMs for highlight detection, Whisper for transcription, and automated editing. Positioned as an open-source Opus Clip alternative.

### 7. [jev-chat/jev-chat-windows](https://github.com/jev-chat/jev-chat-windows)

**560 stars** · Python · Created Sept 21

Windows counterpart to Jarvis. Screenshots the active chat window, runs local offline OCR to read the other party's messages, routes through Jev for intent classification, then generates three candidate replies. Send is always manual.

### 8. [Rizzo-AI-Academy/rizzo-flow](https://github.com/Rizzo-AI-Academy/rizzo-flow)

**496 stars** · Python · Created Sept 21

Open, local take on Jev. Extracts typed decisions from an LLM without generating a single output token. Aims to make the Jev pattern available without depending on TypeSafe AI's proprietary model.

### 9. [kydlikebtc/awesome-jev](https://github.com/kydlikebtc/awesome-jev)

**436 stars** · Python · Created Sept 22

Curated index of 1,207 public Jev resources, organized by decision pattern. Includes source citations, dated link checks, and JSON schema references. Bilingual (English/Chinese).

### 10. [Inkloom-art/inkloom](https://github.com/Inkloom-art/inkloom)

**321 stars** · TypeScript · Created Sept 20

Specialized AI models for logo design. A brand-analysis model turns business context into design constraints, then typography and symbol models construct the mark, and a composition engine produces final lockups with clear-space rules. Currently in early access.
