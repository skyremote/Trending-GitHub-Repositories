# Trending AI Repositories — 2026-10-16

## Editor's Take

The agent ecosystem is no longer a research curiosity; it is a supply chain. This week's repos reveal a pattern: the infrastructure layer beneath AI agents is filling in fast. A $7 ESP32 gives a vision model hands on a real iPhone. A Go binary gives coding agents their own version control. A browser agent ships from Outcrawl that competes with closed alternatives. Meanwhile, the 30-day view shows the model-routing and free-access layer maturing — `dsh-our-free-model` hit 18k stars by removing the last friction between developers and frontier models. The signal is clear: the moat is not the model anymore. It is the tooling that lets agents touch the real world, and this week produced more of that tooling than any week before it.

### Highlights

**[esp32-iphone-agent](https://github.com/onehumanbeing/esp32-iphone-agent)** — A $7 ESP32-S3 gives any OpenAI-compatible vision model full control of a real iPhone. AirPlay provides the eyes; USB HID provides the hands. No Mac, no developer account, no jailbreak. The cheapest physical-world computer-use rig to date.

**[talorys](https://github.com/rociiu/talorys)** — A personal AI agent that lives entirely inside your own Cloudflare account. Chat, memory, tasks, notes, scheduled reminders. Deploy with `npx create-talorys@latest`. Free-tier friendly, single-user, no telemetry. The one-command self-hosted agent.

**[solid-glass](https://github.com/deeplethe/solid-glass)** — A design system purpose-built for AI applications. Material, physical, tactile. Built on React, shadcn/ui, and Tailwind. Addresses the growing gap between agent capabilities and agent UX.

**[mailcheap](https://github.com/marclou/mailcheap)** — Open-source newsletter platform that charges per email sent, not per subscriber. MCP server included so AI agents can manage campaigns. A direct shot at Beehiiv and Substack.

**[new-term-radar](https://github.com/zhuyansen/new-term-radar)** — Scans X, Hugging Face, GitHub, and sitemaps daily to catch new AI terms (model names, product names, repo names) before keyword tools list them. An SEO early-warning system for the AI space.

**[scout](https://github.com/outcrawlai/scout)** — Outcrawl's open-source browser agent. TypeScript, CDP-based, designed for web automation tasks. A credible open alternative in a space dominated by closed products.

**[open_scion](https://github.com/feder-cr/open_scion)** — Version control designed specifically for coding agents. Only two days old and already at 740 stars. Signals that git's assumptions about human workflows are starting to chafe.

**[roast-room](https://github.com/nateherkai/roast-room)** — Seven AI personas (Bezos, Paul Graham, Hormozi, Gary Vee, Buffett, and others) debate your business decision live in Claude Code. Multi-agent simulation applied to strategic thinking.

**[eleven](https://github.com/Zfinix/eleven)** — Agent-first reverse engineering. Any ACP-compatible agent can read, rename, and patch binaries across macOS, Windows, and Linux. Brings AI agents to the disassembly table.
