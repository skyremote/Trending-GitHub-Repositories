Editor's Take

Agent skills are now the dominant distribution format for AI tooling. Six of this week's top ten repos are packaged skills — pixel art generators, architecture diagrammers, 3D simulators, animation decompilers — each a single installable unit that turns a coding agent into a specialist. The shift from "build an AI app" to "ship a skill for someone else's agent" happened quietly, but the star counts say it loudly. Meanwhile, DeepSeek dropped a 14K-star autonomous agent prototype, Microsoft published a paper-backed cost controller for coding agents, and someone unlocked 2x tensor throughput on consumer GeForce cards. The infrastructure layer is splitting in two directions: agents that do more, and agents that cost less doing it.
