Editor's Take

The month's centre of gravity has shifted to on-device and mobile inference. Three of the top five 30-day repos run large models on phones or consumer hardware without a cloud round-trip — DeepSeek's own DeepInfer at 26k stars, dsh-Go putting the DeepSeek Harness in your pocket, and Mika turning an Android phone into an autonomous agent. The signal is clear: the industry is done asking "can we run it locally?" and now asking "what can we automate once we do?"

Meanwhile, the 7-day list tells a different story — the Claude Code ecosystem is spawning tooling at a rate that looks more like a platform launch than an open-source moment. Phone-control MCP servers, Xcode integrations, agent control rooms, and correction-learning skills all appeared in a single week. If you are building agent infrastructure, note that the 30-day chart is dominated by Rust (six of fifteen repos), not Python. The compile-once, deploy-anywhere pattern is winning in agent tooling even as Python still owns model training.
