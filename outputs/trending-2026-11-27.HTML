Trending AI Repos

2026-11-27 UTC

The agent ecosystem has quietly entered its infrastructure phase. This week's standout, fast-anything, is an agent skill that profiles slow code and rewrites the hot 5% in Rust — not an agent itself but a capability agents pick up. The same pattern repeats in opengame (game-dev skill), inspect-robots (robotics eval harness), and llm.asm (inference in bare assembly). The message: the competitive surface has moved from “build an agent” to “build the thing the agent reaches for.” Meanwhile, the 30-day chart is dominated by on-device autonomy — Mika on Android and Poki on iPhone both crossed significant star milestones by putting agents inside native phone apps, not web wrappers. If you are building agent tooling, the question is no longer “which model” but “which device and which runtime.”
