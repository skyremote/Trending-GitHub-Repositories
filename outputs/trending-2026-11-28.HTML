Editor's Take

The week's signal is bifurcation. One track pushes inference to absurdist extremes — llm.asm ships a full Qwen3 inference loop in 12 KB of pure x86-64 assembly, zero dependencies, bootable from bare metal. The other track builds up: agent game studios, agentic commerce protocols, vulnerability scanners purpose-built for agent setups. The 30-day view confirms the pattern at scale — MROffice ships an MCP server so Claude can edit real .docx files, Sapper v2 runs autonomous pentests for eight hours unattended, and mobile-agent-testers puts 20 Claude Code agents on 20 simulated phones in parallel. The industry is no longer asking “can agents work?” but rather “what do agents need to work safely at scale?” Security tooling and inference infrastructure are the quiet winners this month.
